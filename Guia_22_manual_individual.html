GUIA REV. 6 — FORMULÁRIO NO MODELO DO SISTEMA — 22 PÁGINAS

1. Abra individual.html no Chrome.
Ele começa em branco, sem exigir login.
No celular, use o botão Menu do Guia para navegar.

2. Preencha a identificação e os processos.
Informe o nome da fonte na Captação. Selecione essa fonte na Condução
e nos Reservatórios: o vínculo é mantido mesmo se o nome for alterado.

3. Abra Configurações > Classificação APPCC dos itens.
Altere PPHO, PPR, PPR/PPHO, PC ou PCC por item.
É possível editar o foco APPCC e restaurar a classe, o foco e os pesos.
Os cálculos, a matriz e a impressão usam essa configuração.

REGRA DO APPCC
- Havendo PCC aplicáveis, todos os PCC cumpridos atendem ao bloco de 75%.
- Um ou mais PCC não cumpridos descontam 75% uma única vez por grupo/linha.
- Os demais itens dividem 25%; sem PCC aplicáveis, dividem 100%.
- NA é excluído e os pesos são redistribuídos entre os itens aplicáveis.
- Um PCC sem resposta não é considerado cumprido.
- Na situação excepcional de só existirem PCC aplicáveis, o bloco representa 100%.
- Os pesos dos demais itens podem ser personalizados dentro do saldo disponível.
- Avaliações, documentos e observações obrigatórias ainda incompletos ficam Pendente.
- 4.2/4.3/4.5/4.6: 100% Baixo; 76–99% Médio; até 75% Alto.
- Demais processos: 76–100% Baixo; 51–75% Médio; até 50% Alto.
- Decimais abaixo de 76% ou 51% permanecem na faixa inferior, como no sistema.
- A classificação geral considera o maior risco calculado. Se houver módulos
pendentes e nenhum risco calculado médio/alto, indica Não concluído.

4. Use Salvar arquivo para baixar o JSON com todo o preenchimento e configurações.
Confira a confirmação da recuperação automática antes de fechar.
Use Abrir arquivo para continuar com o JSON salvo.
Novo / limpar inicia outro guia, sem herdar dados nem configurações.
A recuperação usa armazenamento local IndexedDB, sem comunicação com Supabase.

5. Fotos, rótulos, documentos legais, responsáveis, assinaturas,
observações, considerandos e medidas adotadas usam o formulário do sistema.
A matriz mostra Baixo/Médio/Alto e respostas S/N/NA em 4.10 e 4.11.

6. Use Imprimir Guia — 22 páginas no menu.
Autorize a janela de impressão se o Chrome bloquear pop-ups.
Selecione A4, escala 100%, sem cabeçalhos/rodapés do navegador.
Use Salvar como PDF para gerar a versão impressa.
O modelo contém as 22 páginas, incluindo documentos legais,
duas páginas de fotos e três páginas de rótulos.
Textos excepcionalmente extensos podem exigir continuação para não serem cortados.

7. Microfone apenas nas observações.
Clique para ditar e novamente para parar. Confira o texto.
Autorize o microfone no Chrome. Se o arquivo local for bloqueado,
use o microfone do teclado ou abra a versão hospedada em HTTPS.
HTTPS não substitui a permissão de microfone do navegador.
O reconhecimento de voz pode exigir internet e usar um serviço do navegador.
O ditado real precisa ser testado no dispositivo; a interface foi validada
com reconhecimento simulado.

COMPATIBILIDADE
Abrir arquivo aceita também o JSON do formulário anterior Guia_Rev6_Chrome.
As respostas consolidadas são transferidas para o modelo do sistema.
As observações por processo vão para Observações gerais.
Confira frases e documentos após essa importação: o formulário anterior
não possuía o mesmo detalhamento documental do aplicativo.
O JSON antigo completo é preservado dentro do próximo backup.
Também aceita o backup JSON de preenchimento com a estrutura m/u do sistema.
Anexos precisam estar incorporados como imagens no JSON; referências de arquivos
remotos exigem acesso pelo aplicativo original e não são baixadas por esta versão.

O aplicativo principal autenticado, o banco definitivo e a publicação GitHub
não foram modificados. Este HTML é uma versão separada para uso sem login.
Não é necessário executar SQL. Para disponibilizar no GitHub Pages,
envie este HTML com seu próprio nome, mantendo o index.html do sistema principal.

TRABALHO EM EQUIPE — IMPORTAÇÃO POR PROCESSOS

ANTES DE DIVIDIR O PREENCHIMENTO
1. Use o HTML atualizado nos três celulares.
2. No guia do responsável pela consolidação, preencha a identificação da inspeção
e confira Configurações > Classificação APPCC.
3. Abra Trabalho em equipe / importar processos no menu.
4. Clique em Gerar arquivo inicial da equipe.
Esse JSON mantém a identificação, os cadastros e vínculos já preparados e a
configuração APPCC, mas sai sem respostas, avaliações documentais, observações,
fotos, rótulos, medidas ou pessoas. O guia aberto não é limpo.
5. Envie o MESMO arquivo inicial JSON e o HTML às três pessoas.
6. Cada pessoa usa Abrir arquivo para carregar esse JSON inicial.
Não use Novo / limpar depois de abrir o arquivo inicial da equipe:
esse botão cria outra inspeção, com outro código comum.
7. Guarde também um JSON do guia do responsável se ele já tiver iniciado a inspeção.

DIVISÃO SUGERIDA
Pessoa 1: 4.1 Captação; 4.2 Condução; 4.3 Reservatórios.
Pessoa 2 (consolidação): 4.10 Controle da Qualidade; 4.11 Responsável e Manipuladores.
Pessoa 3: 4.5 Recepção; 4.6 Higienização; 4.7 Envase.
Cada pessoa clica em Salvar arquivo e envia seu JSON à pessoa 2.
Se possível, envie os processos vinculados no mesmo JSON: 4.1/4.2/4.3 juntos,
4.6/4.7 juntos. As linhas de envase devem manter o vínculo com a higienização.

COMO JUNTAR OS DOIS ARQUIVOS
1. A pessoa 2 abre seu próprio JSON, mantendo seus processos 4.10 e 4.11.
2. Clica em Importar processos e seleciona os JSONs recebidos.
Pode selecionar os dois arquivos de uma vez; cada arquivo será conferido
separadamente, em sequência.
3. No arquivo da pessoa 1, marca 4.1, 4.2 e 4.3.
4. No arquivo da pessoa 3, marca 4.5, 4.6 e 4.7.
5. Confere quantas unidades, itens respondidos e documentos vieram em cada processo.
6. Se já existir preenchimento em um processo escolhido, deve marcar a autorização
de substituição daquele processo. A importação substitui o processo inteiro;
não junta automaticamente respostas concorrentes dentro do mesmo processo.
7. Se APPCC, focos, pesos ou modelos dos considerandos estiverem diferentes,
escolhe manter a configuração atual ou usar a configuração recebida,
separadamente para cada processo selecionado.
8. Clica em Incorporar processos selecionados.
Se um vínculo não puder ser resolvido, nada desse arquivo será incorporado.
9. Confere a Matriz de risco e continua a preencher fotos, rótulos, observações
gerais, medidas adotadas e responsáveis no guia consolidado.
10. Usa Salvar arquivo para guardar o JSON completo.

O QUE É PRESERVADO
- Processos não selecionados, inclusive 4.10 e 4.11 da pessoa 2.
- Identificação e código comum da inspeção do guia que recebe os arquivos.
- Fotos gerais, rótulos, documentos legais, observações gerais, medidas adotadas,
considerações finais manuais, fiscais, responsáveis e assinaturas já presentes.
- Os vínculos das fontes e das linhas de higienização são conferidos e mantidos.
- Os considerandos automáticos, porcentagens e riscos são recalculados.

Arquivos com códigos comuns de inspeção diferentes são bloqueados.
Arquivos antigos sem código comum exigem conferência da identificação e uma
confirmação de que pertencem à mesma inspeção. Identificações incompatíveis
são bloqueadas. Prefira o mesmo arquivo inicial para evitar ambiguidades.
Os processos já incorporados de um mesmo arquivo ficam identificados e não
podem ser reaplicados silenciosamente. Uma nova versão salva pelo colaborador
pode ser importada após a conferência e autorização de substituição.
O histórico local de arquivos incorporados é salvo no JSON consolidado.
Isso é um registro de procedência da consolidação, sem auditoria do Supabase.

IMPORTANTE: Abrir arquivo continua substituindo o guia inteiro.
Para receber somente os processos dos colegas, use Importar processos.

RECUPERAÇÃO AUTOMÁTICA — USO INDIVIDUAL E EM EQUIPE

O guia tenta guardar uma cópia no armazenamento local do navegador enquanto você
preenche. A barra Recuperação informa se a gravação foi concluída ou foi bloqueada.
Após reabrir, toque em Recuperar preenchimento, escolha a envasadora/data/código
corretos e clique em Continuar esta inspeção. Confirme a substituição do guia aberto.

Cada inspeção tem um código próprio e uma cópia separada. As versões de 18 e 22
páginas também ficam separadas. A recuperação inclui o preenchimento, imagens e
registro de importação da equipe; a versão de 22 páginas inclui configurações APPCC.
Novo/limpar inicia outro código sem apagar a recuperação anterior. Para apagar uma
cópia automática, abra Recuperar preenchimento e use Excluir recuperação.

A recuperação é do aparelho e navegador que você usou. Não é enviada ao Supabase
nem aos colegas. Para compartilhar ou consolidar, continue usando os JSONs e
Importar processos. Não use Recuperar preenchimento para receber dados de colegas.

Continue salvando JSONs: a cópia automática pode desaparecer se você limpar os
dados do navegador, usar navegação privada ou perder acesso ao arquivo local.
A gravação ocorre após alterações e em verificações periódicas de cerca de 1 segundo;
fechar abruptamente antes da confirmação pode perder a última alteração. Falta de
espaço ou bloqueio do navegador produz aviso: salve o JSON imediatamente.
No Android content://, a disponibilidade e a continuidade do armazenamento dependem
do navegador e da forma de abertura. Confira a barra e teste reabrindo o guia no seu
celular antes da inspeção. Mantenha o mesmo arquivo HTML e navegador. A recuperação
local não equivale a backup em nuvem. Dados perdidos antes desta versão só podem
ser recuperados se estiverem em um JSON já salvo.

EXEMPLO PRÁTICO — TRÊS PESSOAS

O responsável pela consolidação prepara o guia, gera uma única vez o JSON inicial
da equipe e envia esse mesmo arquivo aos dois colegas. Ele continua no guia aberto.
Colega A preenche 4.1/4.2/4.3; colega B preenche 4.5/4.6/4.7; o responsável preenche
4.10/4.11. Cada colega usa Salvar arquivo e devolve seu próprio JSON preenchido.
O responsável salva uma cópia do seu trabalho antes de importar. Em Importar
processos, seleciona os dois JSONs e confere um por vez. Seleciona somente os
processos de cada colega. Depois completa os dados gerais e salva o JSON final.

Salvar arquivo não fecha nem limpa o formulário. É possível continuar preenchendo
e salvar novamente. Guarde a cópia mais recente e mantenha uma cópia anterior à
importação. Use nomes claros, por exemplo Empresa_Data_Pessoa_Processos.json.

COMO ENCONTRAR O ARQUIVO SALVO

No computador, confira a pasta Downloads ou a pasta escolhida pelo navegador.
No Android, procure em Meus Arquivos/Arquivos > Downloads ou no histórico de
Downloads do Chrome. Se houver arquivos com (1), (2) etc., confira a data e a hora
para escolher o mais recente. O HTML enviado pelo WhatsApp pode abrir com endereço
content://; se houver bloqueios, salve o arquivo no aparelho e tente abrir no Chrome.

DÚVIDAS E CORREÇÕES

- Fechou e o guia abriu vazio? Use Abrir preenchimento (18 páginas) ou Abrir arquivo
(22 páginas) e escolha o último JSON salvo.
- Recebeu arquivo de colega? Use Importar processos. Abrir arquivo carrega o guia
inteiro e substitui o preenchimento aberto.
- Apareceu confirmação de substituição? Confira o processo. A troca é do processo
inteiro: suas respostas anteriores desse processo serão substituídas.
- Código de inspeção diferente? Peça o arquivo preenchido a partir do JSON inicial
correto. Não use Novo/limpar durante a colaboração na mesma inspeção.
- Um resultado ficou Pendente? Confira as respostas e as exigências do processo.
No guia de 22 páginas, confira também documentos e observações obrigatórias.
- Microfone bloqueado? Use o microfone do teclado do celular e confira o texto.
- Impressão bloqueada? No guia de 22 páginas, permita a janela de impressão.
- Foto não apareceu? Selecione novamente a imagem e confira o quadro antes de salvar.
- Importação não entrou? Leia o aviso e confira identidade, processos e vínculos.
Corrija no arquivo do colega e salve uma nova versão para tentar novamente.

CONFERÊNCIA FINAL

Confira identificação, fontes e seus vínculos, respostas Sim/Não/NA, documentos,
observações, percentuais, riscos, matriz, fotos, rótulos e responsáveis. Salve o JSON
consolidado. Gere o PDF pelo botão de impressão do guia e confira todas as páginas.
No uso em equipe, a pessoa responsável completa os dados gerais e anexos: a
importação seletiva não consolida automaticamente todas as páginas do colega.
